GAMEOPTIMIZ 4.0 — ЧТО ИЗМЕНИЛОСЬ
Optimization by zxcillaura

Версия 4.0.0 — полная пересборка линейки GameOptimizer (v1.0 → v2.0 → v3.0 → 4.0).

1. Единый движок
- GUI и CLI применяются через один каталог твиков (ProfileRunner);
  старый дублирующий движок удалён — расхождение «GUI одно, CLI другое» исключено.
- 96 твиков: у каждого детектор состояния, бэкап и откат.
- Профили: Безопасный / Баланс / Экстрим / Вернуть к заводским.
- Кнопка «ПРЕДПРОСМОТР»: dry-run — список действий, риски, перезагрузки,
  пропущенное — до любого изменения.
- Без прав администратора профиль не запускается (система не остаётся
  изменённой наполовину).

2. Диагностика
- HealthScore 0-100 + ТОП-3 ограничителя с кнопкой «Исправить».
- Сеть: замер LAN→DNS→интернет ДО и ПОСЛЕ применения с вердиктом.
- Мышь и клавиатура: input-lag твики + тест очереди событий.
- Формулировки честные: спорные пункты (HAGS, VBS, питание) не обещают
  универсальный прирост — нужен свой бенчмарк.

3. Очиститель
- 19 целей, предпросмотр размера, пагинация.
- Prefetch и шейдерный кэш — выключены по умолчанию (очистка реально
  замедляет первые запуски; оставлены для диагностики).
- Корзина — отдельное подтверждение (окончательное удаление).
- Service Worker браузеров не трогается.

4. Исправления
- EEE-твик: запись в под-ключи устройств (Class\{4d36e972-...}\NNNN),
  а не в корневой Class-ключ; без поддержки драйвером — статус «недоступно».
- Автозагрузка: общее правило (браузеры/оверлеи), без персонального хардкода.
- Убран мёртвый опасный код (bcdedit-флаги, VBS-блоки) — все действия уже
  есть как отдельные контролируемые твики.

5. Интерфейс и система
- PerMonitorV2-DPI, longPathAware, кнопки профилей адаптируются к High-DPI.
- Минимальный размер окна 1120x720.
- Self-contained single-file (~66 МБ), .NET 8, Windows 10/11 x64.

Сборка и проверки:
- dotnet build -c Release -warnaserror: 0 ошибок, 0 предупреждений.
- /doctor, /tweaks, /tweak status: exit 0.
- CI: GitHub Actions (build.yml) собирает каждый push.
