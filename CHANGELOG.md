# История изменений

## Текущая линейка (пересборка)

### [v1.0.0] — 2026-10-09
**Стабильный релиз.**

- Всё из 0.4–0.6 в единой стабильной сборке
- self-contained single-file exe (~66 МБ), FileVersion 1.0.0
- Финальная витрина: README в стиле продаж, hero-превью, полная таблица версий
- CI: GitHub Actions (strict build + publish + artifact)
- Лицензия MIT, issue-шаблоны

### [v0.6.0] — 2026-10-09
**Инженерия.**

- GitHub Actions CI: строгая сборка (-warnaserror) + publish + артефакт на каждый push
- MIT-лицензия, issue-шаблоны (bug/feature)
- Hero-превью интерфейса, бейджи в README
- CHANGELOG и структура `/legacy` зафиксированы

### [v0.5.0] — 2026-10-09
**Витрина и документация.**

- README с таблицей версий и ссылками на релизы
- Старая линейка перенесена в `/legacy` (v1.0/v2.0/v3.0 исходников)
- Честные формулировки: убраны универсальные обещания FPS/пинга
- Обновление описания репозитория

### [v0.4.0] — 2026-10-09
**Пересборка ядра.**

- Единый движок профилей для GUI и CLI (дублирующий легаси-движок удалён)
- Каталог 96 твиков: у каждого детектор состояния, бэкап и откат
- Профили: Безопасный / Баланс / Экстрим / Вернуть к заводским + dry-run «ПРЕДПРОСМОТР»
- Блокировка запуска профилей без прав администратора
- HealthScore 0–100 + ТОП-3 ограничителя с кнопкой «Исправить»
- Очиститель: 19 целей, безопасные дефолты (Prefetch/D3DSCache off, корзина — подтверждение)
- Сеть: замер LAN→DNS→интернет до/после с вердиктом
- Мышь и клавиатура: input-lag твики + тест очереди событий
- Полный CLI: /scan /doctor /report /apply /revert /tweaks /tweak /latency /purge /backup /monitor /bench /session
- Исправлен EEE-твик (под-ключи устройств), автозагрузка без персонального хардкода
- PerMonitorV2-DPI, longPathAware
