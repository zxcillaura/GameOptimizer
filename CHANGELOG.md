# История изменений

## GAMEOPTIMIZ (новая линейка)

### [v1.0.0] — 2026-10-09

Полная пересборка. Единый движок для GUI и CLI, честная диагностика, безопасные
значения по умолчанию.

- **96 твиков** в каталоге; у каждого свой детектор состояния, бэкап и откат
- Профили: **Безопасный / Баланс / Экстрим / Вернуть к заводским** + кнопка
  «ПРЕДПРОСМОТР» (dry-run без изменений)
- Профили не запускаются без прав администратора — исключено «изменено наполовину»
- HealthScore 0–100 + ТОП-3 ограничителя с кнопкой «Исправить»
- Очиститель: 19 целей; Prefetch и шейдерный кэш выключены по умолчанию,
  корзина требует подтверждения, Service Worker браузеров не трогается
- Сеть: замер LAN→DNS→интернет до/после применения с вердиктом
- Мышь и клавиатура: input-lag твики + тест очереди событий
- Игровой режим: закрытие оверлеев, purge standby-памяти
- CLI: `/scan /doctor /report /apply /revert /tweaks /tweak /latency /purge /backup /monitor /bench /session`
- Исправлен EEE-твик (запись в под-ключи устройств, а не в корневой Class-ключ)
- Автозагрузка: общее правило без персонального хардкода
- Убран дублирующий легаси-движок профилей и мёртвый опасный код
- PerMonitorV2-DPI, longPathAware, self-contained single-file publish (~66 МБ)

## Legacy (старая линейка, исходники в `/legacy`)

### [v3.0] — 2026-07-19
- Панель диагностики системы (характеристики ПК, статус античитов)
- Новый вкладочный интерфейс, автоматическая точка восстановления
- Улучшения Windows 11, исправления отключения служб, DNS Jumper

### [v2.0] — 2026-07-15
- DNS Jumper: 30+ серверов с тестом пинга
- Диагностика FACEIT Anti-Cheat (Hyper-V/VBS) и Riot Vanguard (TPM/Secure Boot)
- Профили CS2 и Valorant, очистка системы

### [v1.0] — 2026-07-11
- Первый прототип: режимы «Жесткая/Мягкая», питание и ядра,
  телеметрия/Game Bar, базовая очистка
