GAMEOPTIMIZ 1.0 — СТАБИЛЬНЫЙ РЕЛИЗ
Optimization by zxcillaura

Версия 1.0.0 — финал лестницы: 0.1 → 0.2 → 0.3 (legacy) → 0.4 → 0.5 → 0.6 → 1.0.
Полная история — в CHANGELOG.md и в релизах GitHub.

1. Единый движок
- GUI и CLI работают через один каталог твиков; расхождение
  «GUI одно, CLI другое» исключено.
- 96 твиков: у каждого детектор состояния, бэкап и откат.
- Профили: Безопасный / Баланс / Экстрим / Вернуть к заводским.
- Кнопка «ПРЕДПРОСМОТР»: dry-run до любого изменения.
- Без прав администратора профиль не запускается.

2. Диагностика
- HealthScore 0-100 + ТОП-3 ограничителя с кнопкой «Исправить».
- Сеть: замер LAN→DNS→интернет ДО и ПОСЛЕ применения с вердиктом.
- Мышь и клавиатура: input-lag твики + тест очереди событий.
- Честные формулировки: спорные пункты (HAGS, VBS, питание)
  проверяются своим бенчмарком.

3. Очиститель
- 19 целей, предпросмотр размера.
- Prefetch и шейдерный кэш — выключены по умолчанию.
- Корзина — отдельное подтверждение. Service Worker не трогается.

4. Исправления
- EEE-твик: запись в под-ключи устройств, а не в корневой Class-ключ.
- Автозагрузка: общее правило, без персонального хардкода.
- Убран дублирующий легаси-движок и мёртвый опасный код.

5. Система
- PerMonitorV2-DPI, longPathAware, кнопки под High-DPI.
- Self-contained single-file (~66 МБ), .NET 8, Windows 10/11 x64.
- GitHub Actions CI, MIT-лицензия, hero-превью, полная витрина.

- dotnet build -c Release -warnaserror: 0 ошибок, 0 предупреждений.
- /doctor, /tweaks: exit 0. CI: success.
