GAMEOPTIMIZ 1.0 — ЧТО ИЗМЕНИЛОСЬ
Optimization by zxcillaura

Сделано в этом обновлении:

1. Безопасный очиститель
- Добавлены цели очистки WER, старых логов Windows, INetCache, CbsTemp,
  остатков Windows Update, ETL-трассировок и кэшей браузеров.
- Пользовательские данные браузеров, cookies, пароли и профили не трогаются.
- Удаление файлов отправляет их в Корзину, а не удаляет безвозвратно.
- Windows.old также отправляется в Корзину и по-прежнему требует подтверждения.

2. Вкладка «Мышь и клава»
- Отдельный экран с состоянием, применением и откатом каждого mk-твика.
- Добавлен ориентировочный тест очереди обработки событий интерфейса.
- Центр твиков получил отдельную группу «Мышь и клава».

3. Сеть
- Тест показывает путь LAN → DNS → интернет.
- Добавлено сравнение замеров ДО и ПОСЛЕ с текстовым вердиктом.

4. Главная
- Добавлен блок «ТОП-3 ограничителя».
- Для известных проблем доступна кнопка «Исправить», которая применяет
  соответствующий твик с обычным бэкапом.

5. CLI
- Добавлена команда /doctor:
  железо, HealthScore, применимость каталога и неприменимые твики.

6. Каталог твиков
- Добавлены: perf-svchost-split, ui-anim-off, net-eee-off,
  mk-filter-keys-off, mk-sticky-keys-off, mk-kbd-response, mk-bt-off.

7. Безопасность и доверие
- На странице «Профили» появился dry-run: реальное число действий, уровни риска,
  требования перезагрузки и список неприменимых пунктов.
- Профиль больше не запускается без прав администратора: система не останется
  изменённой только наполовину.
- Формулировки HealthScore больше не обещают универсальный прирост FPS/пинга:
  спорные HAGS/VBS/питание требуют собственного бенчмарка.
- Prefetch и шейдерный кэш выключены по умолчанию; Service Worker браузеров
  исключён из очистки.

8. Интерфейс
- Кнопки профилей адаптируются к узким окнам и High-DPI.
- Минимальный размер окна увеличен до рабочего значения 1120x720.
- В manifest включена поддержка длинных путей; PerMonitorV2 остаётся через API WinForms.

9. Архитектура (единый движок)
- GUI и CLI теперь применяют один и тот же каталог твиков через ProfileRunner.
  Убран отдельный легаси-движок ProfileEngine, который дублировал логику.
- Каталог вырос до 96 твиков. Профили: Безопасный / Баланс / Экстрим,
  плюс «Вернуть к заводским» (откат только тех твиков, у кого есть бэкап).
- Кнопка «ПРЕДПРОСМОТР» на вкладке Профили: безопасный dry-run без изменений.
- Профиль не запускается без прав администратора — система не остаётся
  изменённой наполовину (ранее часть записей молча не применялась).

10. Исправлены небезопасные / нерабочие твики
- net-eee-off: раньше писал EnergyEfficientEthernet в корневой класс Class
  (это не работает — значение живёт в подключах устройств 0000/0001). Теперь
  перебирает реальные под-ключи адаптеров и отключает EEE только там, где
  драйвер поддерживает этот параметр. Без поддержки — твик помечается
  «недоступно», а не лжет «включено».
- Автозагрузка: убран хардкод конкретного GUID одного пользователя. Теперь
  общее правило (Yandex/Chrome/Firefox/Roblox/Riot/Epic/Overwolf/Electron),
  Steam, Discord, античиты и рабочие инструменты не трогаются.

11. Очиститель — безопасные значения по умолчанию
- Prefetch и шейдерный кэш DirectX выключены по умолчанию (их очистка реально
  замедляет первые запуски; оставлены для диагностики).
- Service Worker из браузерного кэша исключён (иначе мог слогать сессии).
- Корзина требует отдельного подтверждения (окончательное удаление).

Проверка:
- Release build (warnaserror): 0 ошибок, 0 предупреждений.
- Publish: win-x64 self-contained single-file.
- /doctor, /tweaks, /tweak status: exit 0.
