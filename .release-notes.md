# GAMEOPTIMIZ 1.0.0

Полная пересборка линейки GameOptimizer. Один движок для GUI и CLI, честная
диагностика, безопасные значения по умолчанию.

## Что нового

- **96 твиков** — у каждого свой детектор состояния, бэкап и откат
- Профили **Безопасный / Баланс / Экстрим / Вернуть к заводским** + кнопка
  **«ПРЕДПРОСМОТР»** (dry-run без изменений системы)
- Профили не запускаются без прав администратора
- HealthScore 0–100 + ТОП-3 ограничителя с кнопкой «Исправить»
- Очиститель: 19 целей; Prefetch и шейдерный кэш выключены по умолчанию,
  корзина требует подтверждения
- Сеть: замер LAN→DNS→интернет до/после с вердиктом
- Мышь и клавиатура: input-lag твики + тест очереди событий
- Полный CLI: `/scan /doctor /apply /revert /tweaks /tweak /latency /purge /backup /monitor /bench /session`
- Исправлен EEE-твик (под-ключи устройств вместо корневого Class-ключа)
- Автозагрузка: общее правило без персонального хардкода
- Убран дублирующий легаси-движок и мёртвый опасный код (bcdedit/VBS)

## Установка

1. Скачай `GAMEOPTIMIZ1.0.exe` из вложений
2. Запусти **от имени администратора**
3. Выбери профиль (рекомендуется «Баланс») → «ПРЕДПРОСМОТР» → «Применить»

## Требования

Windows 10/11 x64. .NET 8 не нужен — exe self-contained (~66 МБ).

> Старые версии v1.0–v3.0 — в папке `/legacy` исходников.
